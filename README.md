# Placement practice questions

Python solutions to coding questions I practised while preparing for placements.

| File | Question |
| --- | --- |
| `rotate_90.py` | Rotate a square matrix 90 degrees clockwise, in place |
| `rotate_180.py` | Rotate a matrix 180 degrees |
| `rotate_270.py` | Rotate a matrix 270 degrees |
| `mirror_pairs.py` | Count pairs where one number is the reverse of the other |
| `max_jump_subarray.py` | Longest run with the same difference between neighbours |
| `neighbours.py` | Simulate K rounds where peaks give to their neighbours and dips take from them |
| `max_score.py` | Take half of the largest element K times and add up the score |
| `reduction_matrix.py` | Check whether a 3x3 matrix can be reduced to zeros |
| `total_event_duration.py` | Add up event durations given start and end times |

Run any of them with `python <file>`.
